# Security Policy

## Reporting a vulnerability

Please report security issues privately to the maintainers (Jason West / West AI Labs). Do not open a public GitHub issue with an exploit, a proof of concept that discloses a secret, or a copy of credentials.

## Secrets

- Never commit `.env` files, API keys, tokens, or private keys.
- Rotate any credential that was committed or pasted into a ticket or chat.
- Name environment variables only; do not paste their values into issues, docs, or agent transcripts.
